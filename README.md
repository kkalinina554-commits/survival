# ЛЕС: ВЫЖИВАНИЕ v2 — 3D survival на Python

Полноценная 3D-игра про выживание в лесу: процедурный мир (каждый запуск — новый),
инвентарь и хотбар, крафты, топор, плавание, кабаны, волки ночью, костры, еда и вода.

Зависимости — всего три: **numpy, glfw, moderngl** (GL 3.3, без лишнего).
Все модели и текстуры генерируются процедурно в коде: сглаженные сферы/тела
с нормалями (не кубики!), текстурный атлас рисуется numpy.

## Установка и запуск

```bash
python3 -m venv venv
venv/bin/pip install numpy glfw moderngl
venv/bin/python game.py            # случайный мир
venv/bin/python game.py --seed 42  # повторяемый мир
venv/bin/python game.py --selftest # тест логики без окна
```

## Управление

| Клавиша | Действие |
|---|---|
| ПРОБЕЛ | старт / рестарт после смерти |
| WASD + мышь | движение / обзор |
| SHIFT | бег (в воде — нырять) |
| ПРОБЕЛ (в воде) | всплыть |
| ЛКМ | удар выбранным предметом (топор рубит деревья и животных) |
| E | взаимодействие: подобрать, попить, собрать ягоды |
| 1–4 | выбор слота хотбара (топор / копьё / еда / руки) |
| TAB | инвентарь |
| C | крафт: 1 — топор, 2 — копьё, 3 — костёр |
| F | быстро поесть |
| H | помощь, ESC — пауза |

## Механики

- **Мир всегда разный**: генерация от seed (параметр `--seed` для повторов).
  Холмы, скалы, песчаные берега, озёра, лес, камни, кусты с ягодами.
- **Хотбар и инвентарь (TAB)**: ресурсы (дерево, камень, волокно, ягоды, мясо),
  инструменты, слоты 1–4.
- **Крафты (C)**: ТОПОР (2 дерева + 1 волокно), КОПЬЁ (1 дерево + 1 камень),
  КОСТЁР (3 дерева + 2 камня). Топором рубить деревья быстрее и можно бить зверей.
- **Плавание**: в воде — W/PROBEL, SHIFT тонет, выносливость/голод не тратятся.
- **Животные**: кабаны днём (мясо), волки ночью (агрессивные).
- **Выживание**: здоровье, голод, жажда; вода — E у озера, еда — ягоды или мясо у костра.
- **Оптимизация**: чанки 32×32 с фрустум-отсечением и отсечением по дистанции,
  один текстурный атлас, слитые меши, анимация ног шейдерно-матричная (без пересборки вершин).

## Структура

- `game.py` — окно, ввод, игровой цикл
- `game_core.py` — мир, генерация моделей/текстур, логика, симуляции
- `game_render.py` — moderngl-рендер и HUD
