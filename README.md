# ЛЕС: ВЫЖИВАНИЕ — 3D на Python

От первого лица, процедурный лес 256×256 м, озёра, день/ночь, добыча ресурсов,
крафт, холод, волки по ночам.

## Библиотеки

Нужны всего три (numpy — почти всегда уже стоит):

```bash
pip install numpy glfw moderngl
```

| Пакет    | Зачем                                                    |
|----------|----------------------------------------------------------|
| numpy    | вся математика и векторная генерация мира                |
| glfw     | быстрое окно + ввод (OpenGL-контекст)                    |
| moderngl | оборачивает OpenGL 3.3 в Python-объекты (шейдеры, VBO)   |

Требования: Python 3.9+, OpenGL 3.3 (есть почти на любой машине).
В Linux дополнительно нужен системный libGL (`sudo apt install libgl1 libglx-mesa0`).

## Запуск

```bash
python game.py            # игра
python game.py --selftest # автопроверка логики без окна
```

## Управление

| Клавиша | Действие                                  |
|---------|-------------------------------------------|
| WASD    | движение                                  |
| Мышь    | обзор (захват курсора)                    |
| SHIFT   | бег (быстрее тратит голод/жажду)         |
| SPACE   | прыжок; старт после смерти                |
| E       | добыча: дерево/камень/ягоды, пить у воды, готовить мясо у костра |
| ЛКМ     | атака (копьё бьёт сильнее и дальше)       |
| F       | есть (ягоды → жареное мясо → сырое)       |
| C       | меню крафта: 1 — топор, 2 — копьё, 3 — костёр |
| H       | помощь                                    |
| ESC     | пауза                                     |

## Выживание

- Днём: руби деревья (топор быстрее), собирай камень и ягоды, пей на берегу.
- Вечером: скрафти **костёр** — без него ночью холод отнимает здоровье.
- Ночью: приходят волки (2 + день/2, максимум 6). Копьё убивает с 2 ударов,
  волк даёт 2 сырого мяса. У костра на E мясо жарится (+45 сытости).

## Оптимизация

- рельеф целиком считается **векторно в numpy**: 65 536 вершин за один прогон
  fBm-шума, без Python-циклов;
- мир разбит на 64 чанка — по одному статичному Indexed-VBO на чанк:
  один draw call на чанк вместо тысяч;
- отсечение чанков **фрустумом** + по дистанции (туман скрывает края);
- вся выпуклая геометрия (деревья, кусты, камни, волк) запечена в статичные
  меши; свойства чанка пересобираются локально только при добыче;
- HUD рисуется одним батчем: пиксельный 5×7 шрифт (кириллица+латиница) —
  атлас-текстура, генерируется при старте, внешних ассетов нет;
- переключение шейдерных программ в кадре: 4 (небо → мир → пламя → HUD).

Файлов: `game.py` (запуск), `game_core.py` (мир/логика, без OpenGL),
`game_render.py` (рендер). Никаких ассетов и сторонних движков.
